# ZAMAKAN Live Earth and PRIME integration
## Verified local integration
- `python workers/osm-live.py --once` downloads an actual OSM replication state and change file, then atomically persists its checkpoint. A single worker on a persistent writable volume runs continuously without `--once`. The server and worker must share OSM_LIVE_FILE. OSM changes are voluntary map edits, not physical construction surveillance; the minutely feed does not guarantee minute-level global completeness. Counts only describe explicit building-tagged ways/relations. Preserve ODbL attribution and assess derivative database obligations.
- For current building geometry, provision PostGIS, osm2pgsql 2.x, storage sized for the geographic import, and Martin. Import a lawful PBF with `osm2pgsql --create --slim -d "$PGDATABASE" extract.osm.pbf`, then `osm2pgsql-replication init -d "$PGDATABASE" --osm-file extract.osm.pbf`; apply `psql -f workers/buildings.sql`. Run `workers/replicate-postgis.sh` as a single worker, configure Martin to expose only the SQL function `zamakan_buildings` using a read-only DB role, HTTPS, CORS, and short CDN cache TTL. For worldwide geometry a planet import, server RAM/disk and benchmark are required; regional imports do not imply world coverage. Set VITE_LIVE_BUILDINGS_BASE to the HTTPS Martin tile source path (no trailing slash), LIVE_BUILDINGS_PUBLIC_BASE to its URL, and configure CORS. The overlay is labelled separately from map basemap.
- Native Google Play Billing 9.1.0 adapter is installed by both android:init and android:sync. Account screen uses Firebase email/password, then shows Play-provided monthly/yearly localized prices. Purchase opens official billing activity; status is not granted until verified and acknowledged by the backend. Restore rechecks all returned purchases. Google account identifiers are bound using hashed Firebase UID; tokens encrypted at rest with AES-GCM. Native plugin is compiled by Android CI; real paid transaction is intentionally not simulated. User can cancel from Google Play and delete Firebase account (deletion does not cancel billing).
- AI comparison accepts two user-authorized images of the same area, dates and explicit submission. Server verifies PRIME entitlement using Google before calling configured Gemini model. Limits are per-user and total per day on a single instance with persistent SQLite; outputs a structured unverified assessment and limitations. This is not a scientific pixel-level or building-damage survey. No image data written to local disk. Do not request or analyze sensitive imagery. Provider model and paid terms require validation.
- RTDN receives authenticated Pub/Sub push with Google OIDC signature, exact audience/service-account allowlist, idempotent message IDs, verifies known purchase again; every protected request also rechecks Google. Unlinked purchases are restored by authenticated client. For production, add durable replay monitoring, alerting and independent scheduled reconciliation for inactive users. Use persistent SQLite single instance (not ephemeral Cloud Run filesystem); for scale move the DB and atomic daily quotas to managed PostgreSQL.
## Owner-only setup, no user API keys
1. MapTiler: https://cloud.maptiler.com/ — select licensed plan and create restricted client key; set GitHub production environment secret MAPTILER_PUBLIC_KEY. Cesium: https://ion.cesium.com/ — approved scoped public token plus photorealistic tiles entitlement; set CESIUM_PUBLIC_TOKEN. These browser credentials are visible in network traffic by design; never use unrestricted admin tokens. Production preflight checks access, not licensing.
2. Google Play Console https://play.google.com/console/ — app package org.zamakan.earth, product zamakan_prime, auto-renew base plans monthly and annual with desired local prices; internal test tracks, license testers, payment profile and bank eligibility. Activate only after testing. Never charge via fake UI.
3. Google Cloud https://console.cloud.google.com/ — enable Android Publisher API; least-privilege service account authorized in Play Console; configure GOOGLE_CLOUD_ADC or securely mount GOOGLE_SERVICE_ACCOUNT_JSON. Create authenticated Pub/Sub RTDN topic/subscription and set audience/service account vars. Never place service account JSON in VITE_ or repo.
4. Firebase https://console.firebase.google.com/ — enable Email/Password Authentication, obtain Firebase project web API key; configure FIREBASE_WEB_API_KEY on backend. Enable abuse protection and test account deletion. Review privacy policy.
5. Google AI Studio https://aistudio.google.com/apikey — create restricted key for approved billing account, choose supported multimodal GEMINI_MODEL. Store only server-side; verify provider terms, data handling and quota. Set PRIME_AI_DAILY_LIMIT and PRIME_AI_GLOBAL_DAILY_LIMIT.
6. Deploy HTTPS backend with persistent volume; use `openssl rand -hex 32` for PRIME_TOKEN_ENCRYPTION_KEY; keep secret in owner's secret manager, encrypted backup and access controls. `ZAMAKAN_ALLOWED_ORIGINS=https://localhost,<web origin>`. Set GitHub variable ZAMAKAN_API_BASE (HTTPS origin), weather config and LIVE_BUILDINGS_BASE if available. Android release preflight fails closed if backend/config missing. Ensure account verification & real Google Play internal testing, actual Android battery/temperature/accessibility measurements, signed APK/AAB upload certificate and legal review.
