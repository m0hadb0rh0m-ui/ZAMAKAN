# زَمَكان 3.0 — دليل المستخدم
**ZAMAKAN Global Intelligence 3.0 · نسخة تجريبية مرشحة RC.3**

زامكان منصة علمية تجمع أدوات فهم الأرض والطقس والفضاء والمناخ والبيئة. ليست نظام إنذار حكوميًا، ولا يمكنها أن تتنبأ بموعد الزلازل، ولا تغني عن الجهات المختصة.

## ماذا يمكنك أن تفعل؟
| القسم | ماذا يفيدني؟ |
|---|---|
| الرئيسية | اختر منطقة أو مدينة، احفظها في المفضلة، وافتح أي مرصد. |
| الخريطة | شاهد الكرة الأرضية في عرض ثنائي أو ثلاثي الأبعاد، وحدد نقطة وقس المسافات والمساحات. |
| الصور الفضائية | اختر أحد خمسة منتجات NASA GIBS وتاريخًا، وتصفح الصور المتاحة؛ لا تُعدّ صورًا لحظية أو تضمن تفاصيل الأشخاص والممتلكات. |
| الطقس | اطلع على نتائج النماذج الجوية وقارن IFS وAIFS وGFS وICON؛ ليست قياسات محطة محلية. |
| المناخ | قارن فترتين متطابقتين موسميًا في ERA5 وتصدّر بيانات الحرارة والهطول. |
| الكوارث | استعرض الزلازل والأحداث المبلّغ عنها من USGS وNASA EONET وGDACS حسب توفر المصدر. |
| CAP | افحص ملف رسالة CAP 1.2 وفق المخطط الرسمي وقواعده الدلالية؛ صحة البنية ليست إثباتًا لهوية المُصدر. |
| البحر والبيئة | استكشف المنتجات البحرية والنماذج المتاحة وجودة الهواء. |
| الفضاء | تعرف إلى حالة الطقس الفضائي والمدارات المدنية القائمة على عناصر مدارية حديثة. |
| GIS | استورد GeoJSON أو KML أو GPX؛ احسب مسافات ومساحات تقريبية، وتقاطع مضلعين، ومقطع ارتفاع لخط من Copernicus DEM. |
| المختبر العلمي | حلّل إشارة مدخلة وعينات FFT وPSD وSTFT مع وحدة وتصدير؛ الأمثلة الاصطناعية ليست رصدًا حقيقيًا. |
| المشاريع | احفظ إعدادات الخريطة محليًا واستعدها وصدّرها؛ لا تُرفع إلى خادم تلقائيًا. |

## كيف أقرأ البيانات؟
- **متاح:** نجح جلب منتج المصدر؛ لا يعني أن كل طلب جغرافي صالح أو أن البيانات لحظية.
- **مخزن مؤقتًا / قديم:** بيانات سابقة معلّمة بوقت الجلب؛ أعد التحقق قبل الاستنتاج.
- **غير متاح:** فشل المصدر أو لا توجد نتيجة صالحة. لا يستبدل التطبيق الفشل بقيمة وهمية.
- **نموذج / توقع:** تقدير حسابي؛ **إعادة تحليل**: دمج تاريخي للبيانات والنماذج؛ **مبلّغ عنه**: تقرير منشور، ليس تنبيهًا محليًا معتمدًا.
- عند العمل باتصال محدود، استخدم وضع توفير البيانات واختر الطبقات الضرورية.

## حدود الإصدار
الخدمات التي تحتاج إلى مفاتيح أو حسابات أو خادم إنتاج، والتغطية العالمية الكاملة للتحذيرات، وبيانات المباني عالية الدقة عالميًا، والإشعارات المعتمدة والتوقيع الإنتاجي ليست مكتملة. لا توجد شهادة أمان أو اختبار ميداني شامل على جميع أجهزة Android وWindows. راجع [مصفوفة تنفيذ الوثيقة](release-3.0.md).

## التوقعات التجميعية GEFS
من الرصد ← توقعات التجميع ← جلب توقعات ثلاثة أيام. اختر الساعة بالتوقيت العالمي؛ يعرض التطبيق المئين 10 والوسيط والمئين 90 والمتوسط وعدد الأعضاء الصالحين ونسبة الأعضاء بهطول 1 مم أو أكثر في ساعة. لا تمثل هذه النسبة احتمالًا معايرًا، ولا مجال المئينات ضمانًا. يمكنك تصدير CSV أو JSON مع بيانات المصدر.
